# 위키 스킬 은퇴

이 스킬의 신규 배포와 확인 워처는 은퇴했다. `wiki_gate` 승인 카드나
`wiki_cli` 쓰기 명령으로 새 요청을 처리하지 않는다. YooDori의 위키 명령도
제거됐다.

소유자가 Discord에서 노트 작성을 요청하면 일반 Obsidian 쓰기를 사용한다.
계정 안의 쓰기는 dori-gate가 소유자 메시지·변경 기록·복구 경로를 확인한 뒤
카드 없이 처리한다. 외부 공유·권한 부여는 별도 승인 대상이다.

`scripts/`는 기존 지식 조회와 저장 형식·과거 승인 기록의 호환성을 위한
라이브러리로 보존한다. 새 승인 경로가 아니며 워처를 다시 설치하지 않는다.
