## 형만 하는 일(명시적 예외)

공용 경로도 카드를 올리지 않고 사유와 함께 거절하는 일이다(`automation/effect_request/policy.py` 의 `OWNER_ONLY`, exit 4 `code=owner-only:<종류>`).

| 종류 | 예 | 사유 |
|---|---|---|
| `credential` | 비밀번호·키·토큰 변경 | 자격증명은 형이 직접 바꾼다 |
| `payment` | 결제·송금·구매 | 돈이 나가는 일은 형이 직접 한다 |
| `identity` | 로그인·2단계 인증·OAuth 동의(`gws auth`·`gh auth`) | 본인 확인은 형만 할 수 있다 |
| `privilege` | sudo | 관리자 권한 작업은 형이 직접 한다 |
| `self-approval` | 승인 반응(✅) 대리 누름 | 승인은 형의 ✅ 뿐이다 |

전용 경로가 있는 효과(메일·일정·할 일·Obsidian·Drive 공유·특허 반출)를 공용 경로로 요청하면 `code=dedicated:<종류>` 로 그 전용 명령을 안내한다. 오토파지에 도구 자체가 없는 일(예: 카카오톡 방 게시)은 승인 경로가 아니라 도구가 없다고 보고한다.

## 런타임 가드

에이전트 답장이 승인 카드 링크 없이 ✅ 를 요청하면, 게이트웨이 `transform_llm_output` 훅(`automation/interop/chat_approval_guard.py`)이 그 줄을 "이 작업은 표준 승인 경로를 거치지 않았다" 안내로 바꾼다. 채팅 메시지의 ✅ 는 어떤 워처도 읽지 않기 때문이다.
