# 보고서 제목

`skills/report/scripts/report_core.py`의 `assemble_report`가 보고서 맨 위 제목을 만든다.
모델 초안이 첫 줄에 H1 제목을 돌려주면 그 줄만 제외하고 `핵심 내용`에 넣는다.
따라서 노트 제목을 제목으로 쓴 재생성 보고서에도 문서 제목은 한 번만 나타난다.
하위 절과 본문, 끝의 근거 노트 목록은 그대로 유지한다.

선택 노트와 명시적 재료 파일 모두 같은 조립기를 사용한다. 모델 호출·입력 한도·발행
경로·승인 정책은 바뀌지 않는다. 회귀는 `tests/unit/test_report_title.py`에서 더미
노트 파일을 읽어 문서 H1 수와 본문·출처 보존으로 확인한다.
