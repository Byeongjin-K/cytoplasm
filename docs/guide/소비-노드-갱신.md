# 소비 노드 갱신 가이드 — 받은 릴리스를 전량 반영한다

**소비 노드**는 공개 cytoplasm 의 서명 릴리스를 받아 쓰기만 하는 노드다. 직접 릴리스를 자르지 않는다. 설치는 [install.md](install.md)가 맡는다. 이 문서는 설치 **뒤** 새 릴리스를 노드 전체에 반영하는 방법만 다룬다.

근거는 실제 소비 노드에서 처음 전량 반영할 때 막힌 기록이다: [소비 노드 첫 전량 반영 공백](../troubleshooting/소비-노드-전량-반영-공백.md).

## 1. 저절로 되는 것과 아닌 것

| 표면 | 누가 갱신하나 |
|---|---|
| 릴리스 트리 `/srv/autophagy-agent-current` | 2분 리컨실러가 서명 태그를 검증해 저절로 수렴한다 |
| 스킬 마운트, 계정 홈 패키지, 정기 작업, 게이트웨이 묶음 | `automation/deploy_all.sh --apply` 가 한다. 리컨실러는 하지 않는다 |
| 배포 영수증 `/srv/autophagy-private/deploy-all/receipt.json` | 전량 반영이 깨끗하게 끝날 때만 써진다 |

릴리스 트리만 새것이고 전량 반영을 한 번도 안 돌린 노드는 "새 릴리스를 받은" 상태가 아니다. 스킬과 정기 작업은 예전 판이 그대로 돈다.

## 2. 첫 전량 반영 순서

1. **체크아웃을 받은 서명 태그에 맞춘다.** 배포기는 기본으로 `origin/main` 과 바이트가 같은지 확인한다. main 이 태그보다 앞서 있으면 모든 배포기가 `DEPLOY-BLOCK … differs from origin/main` 으로 멈춘다. 그때는 검사를 끄지 말고 기준만 태그로 준다:
   ```bash
   export DEPLOY_PROVENANCE_REF=v2.6.3   # 체크아웃한 태그
   ```
2. **리허설부터 돌린다.** 아래 명령은 노드에 아무것도 쓰지 않고 마지막 줄만 남긴다. `REHEARSAL-OK` 가 아니면 그 단계의 거절 이유를 먼저 해결한다.
   ```bash
   automation/deploy_all.sh --rehearse
   ```
3. **판정을 본다.** `automation/deploy_all.sh --plan` 이 할 일을 나열한다. `ACT|owner|…` 줄은 사람(root)만 할 수 있는 일이라 배포기가 하지 않는다.
4. **반영한다.** `automation/deploy_all.sh --apply`. 끝에 `receipt written` 이 나오면 영수증이 생긴 것이다.

## 3. 알려진 공백과 현재 상태

| # | 증상 | 상태 |
|---|---|---|
| 1 | 게이트웨이를 멈춘 노드에서 cron 목록 전체가 판독 불가 | v2.6.3에서 고침(새 Hermes 경고 문구 인식) |
| 2 | `memory-choices` 폴더의 setgid 가 빠져 영구 거부 | v2.6.3에서 고침(상속으로 만들고, setgid 만 빠진 빈 폴더는 다시 만든다) |
| 3 | 옛 노드에서 interop 배포가 새 규칙 확인 단계에서 멈춤 | v2.6.3에서 고침(게이트 없는 옛 런타임은 릴리스 트리로 확인) |
| 4 | 서명 태그 체크아웃인데 `origin/main` 기준으로 막힘 | 위 2-1의 `DEPLOY_PROVENANCE_REF` 로 진행 |
| 5 | 소유자가 끈 정기 작업을 배포기가 다시 켬 | v2.6.5용 `~/.hermes/release-flags/owner-timers-off`(릴리스 호스트)에 이름순·중복 없이 LF로 끝나는 작업명 목록을 적어 같은 HEAD 릴리스 승인에 묶는다. [사용법](../기능소개/형이-끈-정기-작업-유지.md). 되돌리기: 호스트 파일 삭제 후 새 릴리스 승인 |
| 6 | 릴리스 카드 채널과 peer 증명 채널이 어긋나 스킬 마운트가 안 됨 | 이 노드의 승인 채널 설정에 따라 다르다. 공백 문서의 노드 조치를 참고한다 |
| 7 | 설치한 적 없는 옛 서비스를 끄는 스위치가 실패 | v2.6.3에서 고침(설치 안 된 유닛은 이미 꺼진 것으로 본다) |
| 8 | 영수증이 없으면 새 릴리스가 멈춘 게이트웨이를 다시 켬 | v2.6.3에서 고침(승인된 정지가 영수증 옆에 표식을 남긴다) |

## 4. 하지 않는 것

- 검사를 꺼서 통과시키지 않는다. 탈출구(`DEPLOY_ALLOW_UNPUSHED=1` 등)는 샌드박스 전용이다.
- 이 문서는 소비 노드가 스스로 서명 릴리스를 자르는 경로를 다루지 않는다. 릴리스 서명키는 업스트림 유지보수자만 가진다([manual-maintainer.md](manual-maintainer.md)).
