# 도리 기본 설치로 전환하고 기존 노드의 멈춘 Hermes는 보존합니다

MAJOR: 운영자 조치 필요 — 공개 설치 명령의 프로필 생략은 이제 도리입니다. 기존 Hermes 설치 자동화는 `--profile core|rag|report-hub|full`을 명시하십시오.
MAJOR: 운영자 조치 필요 — 봇 전환 배포를 검증한 뒤, 기존 정지·채널 전환 스위치를 유지한 별도 메이저 카드로 출시합니다. 노드에서 설치기를 다시 실행하지 않습니다.
MAJOR: 운영자 조치 필요 — 정지 보존 리컨실러 수정을 선행 봇 전환 릴리스에 먼저 포함합니다. P6에만 실으면 업데이트 전 코드를 읽은 첫 전환은 여전히 게이트웨이를 재시작합니다.

## 바뀐 것

- `python3 -m automation.install`, 설치 마법사의 첫 선택, quickstart의 기본 경로가
  `dori/pin.toml`에 고정된 포크와 리드+YooDori 역할을 설치합니다.
  옥돌·무돌은 선택 역할이며 개인값은 복사하지 않습니다.
- 신규 기본 경로는 Hermes 설치 전제, cron 등록, 게이트웨이 drop-in,
  interop·memory provider 플러그인, 호환 패치를 설치하지 않습니다.
- 기존 노드의 명시적 레거시 유지보수와 업무 런타임은 보존합니다.
  도리 config·사용자 지침은 덮어쓰지 않으며 다른 커밋의 포크는 자동 전환하지 않습니다.
- 설치 기본값 변경을 메이저 신호로 검사하여 patch·minor 출시를 거부합니다.

## P5 삭제 — 이번 릴리스에 포함하지 않음

카드 표시: **P5 삭제 미포함: 멈춘 Hermes 잡·peer 계정·게이트웨이 유닛은 보존.**

소유자 결정: **“멈춘 Hermes 잡 33개 지울지” — 미결, 기본값 보존.**
peer 계정·홈, 게이트웨이 유닛, 일시정지 잡, peer 봇·attestation 제거는 별도 P5
단계이며 이 릴리스는 삭제 명령을 실행하지 않습니다. 선택하면 그 목록과 백업·복구
조건을 독립 카드 항목과 별도 릴리스 노트에 넣습니다.

## 업그레이드·복구

이미 도리가 대화를 받고 사용자 타이머가 업무를 실행하는 노드는 기존 서명 업데이트로
전진합니다. 활성 포인터와 전량 반영 영수증의 SHA, 게이트웨이 정지 유지,
업무 타이머·통지를 확인합니다. 신규 설치기는 도리 CLI와 역할 구성까지 준비하며,
업무 금고나 외부 계정 로그인·봇 기동을 대신하지 않습니다.

취소는 직전 검증된 서명 태그의 동작을 복구하는 PR을 **더 높은 버전**으로
출시합니다. 옛 태그를 강제 설치하거나 롤백 방지 floor를 낮추지 않습니다.
도리·Hermes의 기존 개인 데이터는 삭제하지 않습니다.
