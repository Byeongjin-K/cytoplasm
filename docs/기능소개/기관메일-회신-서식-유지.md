# 기능 소개 — 기관메일 회신 서식 유지 (원본 HTML 인용 · 맑은 고딕 회신문)

**완료:** 2026-10-19 · **스킬:** `mail` · **모듈:** `skills/mail/scripts/mail_quote.py`, vendor `mailon/{writer,send,send_trigger,main}.py`

## 무엇을
기관메일 회신이 받은 메일을 **원래 서식(표·색·굵기·글꼴) 그대로** 아래에 단 채 나가고, 새로 쓴 회신 글은 **맑은 고딕 10.5pt, 줄 간격 160%** 로 나간다. 새 메일 작성과 전달 메모도 같은 글꼴이다. 승인 카드에는 지금처럼 회신 글만 보이고, 인용은 `- 원문 인용: 원본 서식 유지` 한 줄로 알린다.

## 왜
소유자 결정(2026-10-19, Q46·Q47): "앞으로 메일 회신할 때, 기존 메일이 아래 달리는데 그 메일의 글씨체랑 띄어쓰기, 줄 간격 등이 좀 가시성이 안좋네. 원본 유지하면서 보낼 순 없나? 그리고 회신하는 글의 글씨체도 가시성 좋은것으로 선택하고 싶어."

원인은 두 가지였다. ① mailon 수집기가 원문 HTML 을 읽어 놓고도 저장할 때 글자(`get_text`)만 남겨서, 인용에는 줄과 칸이 흩어진 글자만 붙었다. ② 발송이 편집기에 `innerText` 로 평문을 넣어서, 편집기 기본 서식(굴림 10pt·150%)으로 나갔다.

## 핵심 동작 (불변식)
- 수집: mailon writer 가 원문 HTML 을 markdown 옆 `<같은 이름>.html` 로 함께 저장한다(새로 수집되는 메일부터). wrapper `get --body --with-html` 만 그것을 내준다(`--masked` 에서는 내주지 않는다).
- 초안: 동결 argv 에 평문 `--body`(예전과 같은 회신문+평문 인용)와 `--body-html`(회신문 HTML + HTML 인용)이 함께 실린다. 둘 다 승인 해시에 묶이고, 레코드의 `quote_html`·`quote_format`(`original`|`text`)도 묶인다. 이 키가 없는 옛 초안의 해시는 바이트 그대로다.
- 인용 HTML 정리(`mail_quote.sanitize_html`, 허용 목록): `<script>`·`<style>`·프레임·`<object>`·폼은 내용째 지운다. `on*` 이벤트와 목록 밖 속성도 지운다. 링크는 http(s)·mailto 만 남긴다. 이미지는 본문에 들어 있는 `data:image/…` 만 남기고, 원격·`cid:` 이미지는 alt 글자로 바꾼다(열자마자 바깥으로 요청이 나가지 않는다). CSS 선언 가운데 `url(`·`@import`·`expression(` 가 든 것도 지운다.
- 크기 상한: 정리한 원문 HTML 이 100,000바이트를 넘으면(argv 한 인자의 리눅스 상한은 128KiB) 평문 인용으로 내려간다. 원문 HTML 이 없을 때(이 변경 전에 수집된 메일)도 평문 인용을 줄바꿈·띄어쓰기를 지킨 HTML 로 보내고, 카드는 `- 원문 인용: 포함 (원본 서식 없이 글자만)` 으로 알린다.
- 발송: `send --body-html` 이 있으면 편집기 iframe 에 `innerHTML` 로 넣는다(재채움은 편집기 API `setContent`). 발송 검증은 그대로다: 평문 `--body` 의 첫 줄 표식이 실제 발송 내용에 있어야 하고(편집기가 `&`·`<`·`>` 를 엔티티로 바꾼 표기도 같은 글자로 본다), To·Cc·Bcc 는 정확히 일치해야 한다. 전체답장 Cc 규칙도 바뀌지 않았다.
- 실행 경계: 프리플라이트가 회신문을 고치면 HTML 본문도 고친 회신문+동결 인용으로 다시 만든다. Drive 공유 링크 자리(`<Drive 링크>`)는 두 본문에서 모두 링크로 바뀐다.

## 사용 시나리오
1. **(기본)** 병진 님 "3번 메일에 참석한다고 회신해줘" → 카드에 회신 글 + `- 원문 인용: 원본 서식 유지` → ✅ → 상대는 맑은 고딕 회신 글 아래에서 자기가 보낸 표·색 그대로의 원문을 본다.
2. **(옛 메일)** 이 변경 전에 수집된 메일에 회신 → 카드에 `- 원문 인용: 포함 (원본 서식 없이 글자만)` → 인용은 줄바꿈과 띄어쓰기를 지킨 글자로 나간다.
3. **(안전)** 원문에 추적 이미지나 스크립트가 있어도 → 발송 HTML 에는 남지 않는다(정리 단계에서 제거).
