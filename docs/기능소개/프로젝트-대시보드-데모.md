# 프로젝트 대시보드 데모

## 무엇을

`python3 -m automation.project_board demo`로 가상의 프로젝트·할 일·메일을 채운 보드를 연다.
실제 보드나 메일을 읽거나 바꾸지 않고, 모델·Discord·Drive를 호출하지 않는다.

## 왜

실제 프로젝트와 사람, 메일을 화면에 노출하지 않고 대시보드의 사용 흐름을 설명하기 위해서다.
날짜는 실행일 기준으로 잡으므로 지연과 이번 주 마감 사례가 매번 보인다.

## 사용 시나리오

- 명령 실행 후 출력된 `DEMO` 주소를 브라우저로 연다. 활성 프로젝트 4개, 지연·진행·완료 할 일,
  보관한 프로젝트 1개와 검토 대기를 살펴보고 근거 링크로 가상 메일을 연다.
  Ctrl-C로 끝내면 서버와 자동 생성한 임시 폴더가 정리된다.
- `--port 8811 --root /tmp/project-board-demo`처럼 빈 폴더를 지정하면 종료 뒤에도 데모 DB가 남는다.
  같은 폴더로 다시 실행하면 기존 `board.db`를 덮어쓰지 않고 종료 코드 2로 멈춘다.
  실제 보드 경로와 그 하위 경로, 다른 파일이 든 폴더도 거부한다.

## 관련

- 안내: [프로젝트 대시보드 가이드](../guide/프로젝트-대시보드.md#데모-보드)
