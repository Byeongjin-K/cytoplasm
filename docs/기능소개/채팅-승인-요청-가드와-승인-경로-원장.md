# 외부효과 승인 경로 원장

## 무엇을
계정 밖 효과의 카드 생산자·승인 워처·검증 테스트를 빌드에서 연결한다.
계정 안 일정·문서·할 일·Obsidian 쓰기에 카드 생산자를 요구하지 않는다.
Hermes 전용 도구 분류기와 플러그인은 은퇴했으며 채팅 가드 모듈은
레거시 라이브러리로만 남는다.

## 왜
옛 원장은 내부 노트와 할 일에도 카드를 강제했다. 현재 규칙에서는
소유자 Discord 명령을 dori-gate가 확인하고 카드 없이 처리해야 한다.
외부효과만 기존 카드·워처·실행 영수증의 완결성을 확인한다.

## 사용 시나리오
개인 할 일 등록은 소유자 메시지 확인 뒤 즉시 반영한다. 메일 발송이나
외부 참석자 초대는 기존 전용 카드를 만들고 소유자 승인 뒤 실행한다.
카드 대상인데 워처나 테스트가 없는 생산자를 원장에 등록하면 빌드가 실패한다.
채팅 메시지의 반응이나 다른 봇의 승인은 실행 권한으로 받지 않는다.
