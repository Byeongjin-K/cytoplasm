# 위키 스킬 은퇴 — 계정 안 노트는 카드 없이

## 무엇을
Hermes 전용 wiki 스킬과 확인 워처의 신규 배포를 은퇴한다.
위키의 저장 형식·지식 조회 라이브러리와 과거 승인 기록 호환 코드는 보존한다.
새 노트 요청에는 `wiki_gate` 카드를 만들지 않는다.

## 왜
모든 쓰기에 승인 카드를 요구하던 규칙은 은퇴했다. 소유자 계정 안의
노트는 일반 Obsidian 쓰기로 처리해야 같은 내용을 카드로 다시 승인하지 않는다.

## 사용 시나리오
소유자가 Discord에서 “이 내용을 노트에 정리해줘”라고 요청하면 YooDori는
dori-gate로 소유자 메시지를 확인하고 계정 안 Obsidian에 저장한다.
변경 기록·하루 요약·되살리기를 남기며 별도 저장 카드는 없다.
외부 공유를 요청하면 공유 경로의 승인을 먼저 받는다.

옛 `skills/wiki/deploy.sh`를 호출하면 `WIKI-RETIRED`와 exit 4로
거부하며 워처를 다시 설치하지 않는다. 은퇴 선언은 잔존 사본을 관측하고,
서명 릴리스의 제거 경로가 옛 확인 타이머를 정리한다.
