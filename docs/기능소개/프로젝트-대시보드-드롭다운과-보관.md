# 프로젝트 대시보드 — 프로젝트 드롭다운과 보관함

## 무엇을

할 일·일정 탭 위의 프로젝트 고르기가 버튼 줄에서 **드롭다운** 하나로 바뀌었다. 끝난 프로젝트는 프로젝트 화면에서
**「보관」**하면 메인 화면들에서 사라지고 새 **「보관함」** 탭에서만 보인다. 프로젝트 순서는 함수 하나가 정한다(지금은 이름순).

## 왜

프로젝트마다 버튼이 하나씩 늘어나 과제가 많아지면 고르기 어려웠다. 끝난 과제도 요약·할 일·일정에 계속 섞여 있었다
(2026-10-15 소유자: "가상 과제 알파, 감마, 베타 이런 식으로 별도의 버튼을 만들어 놓으면 과제 수가 많아졌을 때 클릭하기
힘들어. 그거 드롭다운으로 만들어. 정렬은 주관 순서대로 하고 그리고 내가 프로젝트를 보관 모드로 보낼 수 있게 해놔").

## 사용 시나리오

- **드롭다운으로 고르기**: 일정 탭 위 「프로젝트」 드롭다운에서 「가상과제 베타」를 고르면 그 과제의 마감만 남는다.
  주소가 `#schedule?p=…` 로 바뀌어 뒤로 가기·공유가 그대로 되고, 「전체 프로젝트」를 고르면 풀린다. 휴대폰에서는
  기기 기본 목록 선택기가 열린다.
- **보관하기**: 「가상과제 감마」 화면 머리글의 「보관」을 누르고 확인한다 → 보관함 탭으로 옮겨 가고 감마 카드에
  「보관 10-15 15:30 KST · <테일스케일 로그인>」이 붙는다(할 일 체크와 같은 신원 — 최근 기록에도
  누가 체크·보관했는지가 남는다). 요약·프로젝트·할 일·일정·근거와 드롭다운에서는 감마가 사라진다.
- **보관한 과제 보기·되돌리기**: 보관함에서 감마 카드를 누르면 할 일·일정·근거가 그대로 있다(지워지지 않는다).
  「보관 해제」를 누르면 메인 화면에 다시 나온다.
- **보관 뒤 새 일**: 보관한 감마에 새 메일 카드가 승인되면 감마는 보관함에 그대로 있지만, 요약에
  「보관한 프로젝트에 새 할 일 — 가상과제 감마 · 새 할 일 2건」이 뜨고 보관함 카드에도 표시된다.
- **거부 경로**: 토큰도 허용된 테일넷 로그인도 없는 요청, 다른 사이트에서 온 요청은 보관되지 않는다(401/403).
  일일 요약 메일 첨부(읽기 전용 사본)에는 보관 버튼이 없고 누가 보관했는지도 실리지 않는다.
