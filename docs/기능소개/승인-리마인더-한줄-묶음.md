# 승인 리마인더 한 줄 묶음

승인 대기 알림은 `⏰ 승인 대기 N시간 · <승인 카드 링크>` 한 줄로 표시한다.
같은 워처 틱에서 같은 채널이나 스레드로 보낼 알림은 메시지 하나에 카드별 한 줄씩 모은다.
여러 카드의 반복 알림이 대화를 밀어내는 문제를 줄인다.

## 사용 시나리오

- 같은 일정 스레드의 카드 두 장이 알림 시각에 도달하면 두 줄짜리 메시지 하나가 온다.
  각 링크는 해당 승인 카드를 가리킨다. 다른 스레드의 카드는 별도 메시지로 간다.
- 길드 좌표를 모르면 링크만 생략한다. 명시적인 DM 기록이 아니면 DM 링크를 추측하지 않는다.
- 전송이 실패해도 그 시간 구간의 카드별 claim은 유지한다.
  같은 구간에 재전송하지 않고 다음 알림 구간에 다시 시도한다.

경과시간은 완료된 시간 단위로 표시한다. 알림 주기·카드 승인 해시·리액션 판정은 바꾸지 않는다.
알림에는 승인이나 취소를 요청하는 반응 기호를 넣지 않으며 새 스레드를 열지 않는다.
