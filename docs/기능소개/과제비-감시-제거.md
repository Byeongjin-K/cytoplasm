# 과제비 감시 제거

## 무엇을

budget 스킬을 없앴다. 과제비 조회(`!budget`), 30분마다 시트를 읽던 `budget-watch`, 변경을 감지하면 올리던 과제비 요청 메일 승인 카드가 모두 빠진다.

## 왜

2026-10-22 0시, `budget-watch` 실패 통지에 형이 "이 기능 없애놔 나중에 다시 만들거야"라고 답했고, 0시 14분에 "시트도 그냥 삭제해 그리고 옛 설계도 필요없어 헤르메스 시절에 쓰던 기능들 모든 설계는 남기지마"라고 더했다.
시트 읽기 실패 같은 이유로 실패 통지가 되풀이해 왔고, 쓰지 않는 감시가 알림만 만들고 있었다.
고쳐서 살리는 대신 지금은 걷어내고, 필요해지면 새로 만든다.

## 사용 시나리오

1. 노드 타이머는 형 답장 직후(2026-10-22 0시) 꺼서 `budget-watch` 실패·회복 알림이 더 오지 않는다. 다음 승인된 릴리스가 남은 유닛·래퍼·마운트를 지운다.
2. 형이 `!budget`으로 과제비를 물어도 응답할 스킬이 없다. 과제비 요청 메일 카드도 더는 올라오지 않는다.
3. 옛 설계는 문서로 남기지 않는다. 다시 만들 때는 새로 설계한다.

쓰던 과제비 시트는 형 말대로 유돌이 Drive 휴지통으로 옮긴다(이 저장소 코드는 시트를 건드리지 않는다). Drive 분류의 `예산` 폴더 어휘와 메일 분류의 💳 예산 표시는 남는다(메일 분류는 이 스킬과 별개다).
PR만으로 노드가 정리되지는 않는다. 릴리스 승인 전까지는 꺼진 타이머 파일과 래퍼가 노드에 남는다.

## 관련

- `automation/retired_jobs.py`: `budget-watch` 은퇴 선언이 릴리스 때 systemd 사용자 타이머·서비스 `autophagy-cron-budget-watch`와 `~/.hermes/scripts/budget_watch.py`를 지운다.
- `automation/deploy-skill.sh budget --remove`: 릴리스 계획에 고아로 보고된 live 마운트 `/srv/autophagy-skills/live/budget`을 운영자가 걷는다.
- 승인: 노드 정리는 같은 HEAD의 릴리스 승인(✅)에 묶인다.
- 보존 어휘: 저장된 승인 기록을 읽기 위한 `ApprovalKind.BUDGET_MAIL`.
