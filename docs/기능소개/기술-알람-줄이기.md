# 기능 소개 — 기술 알람 줄이기 (Q281)

**완료:** 2026-10-19 · **모듈:** `automation/release_applied_state.py`, `automation/healthcheck_notify.py`

## 무엇을
- 릴리스가 적용된 뒤 운영자가 고칠 기술 항목은 디스코드에 올리지 않는다. 릴리스 기록(`RELEASE-OPS …`)과 운영자 inbox 한 줄(`kind: release-ops`)에만 남는다. 형 채널의 `✅ 적용됨` 한 줄은 그대로다.
- 헬스체크는 같은 검사가 10분 넘게 계속 실패할 때만 #dori-pair 에 한 번 올린다. 한 번 깜빡인 실패는 올리지 않고, 회복은 알리지 않는다.

## 왜
형 결정 Q281(2026-10-19 18:04 KST): "릴리스 운영자 조치는 디스코드에서 빼고, 헬스체크는 10분 넘게 이어질 때만 #dori-pair". v2.6.5 적용 뒤 #dori-pair 에 운영자 항목 두 통이 올라오자 형이 "이거 왜 여기 올려?"라고 물었다.

## 사용 시나리오
- **(릴리스 뒤 허용 목록 어긋남)** 형 채널 `✅ v2.6.6 적용됨 — …` 한 줄. 운영자는 inbox 의 `release-ops` 줄로 항목·안내 명령을 받는다. 디스코드에는 아무것도 없다.
- **(헬스체크 잠깐 실패)** 5분 뒤 회복 → 아무 통지 없음. **(계속 실패)** 10분째 스윕에서 #dori-pair 에 한 번, 그 뒤 같은 사건은 다시 올리지 않는다.
- **(inbox 미설정 설치)** 항목은 릴리스 기록에만 남는다.

## 관련
- 회귀: `tests/unit/test_q281_alerts.py`(10분 지속·깜빡임·inbox·전송 실패 시 무기록).
- 설정: `RELEASE_OPS_INBOX` 또는 `~/.hermes/release-ops-inbox`(설치별 경로, 코드에 없음).
