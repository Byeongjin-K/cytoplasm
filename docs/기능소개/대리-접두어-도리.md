# 대리 요청 접두어를 "도리 대리"로

## 무엇을

대리 봇이 `#agent-chat` 에 옮겨 쓰는 소유자 요청의 접두어를 `[도리 대리 · 소유자 요청 <원문 링크>] <본문>` 으로 정했다. 옛 접두어 `[오모냥 대리 · 소유자 요청 …]` 은 비권장으로 남겨 전환 기간 동안 계속 받는다.

## 왜

2026-10-11 소유자 지시: "오토파지 대리 접두어는 항상 \"도리 대리\" 로 하게 바꿔". 대리 봇의 이름이 바뀌었으므로 요청 머리말도 그 이름을 쓴다. 이미 보낸 요청과 누락 안전망의 재전송은 옛 이름을 달고 있으므로 한 번에 끊으면 그 요청들이 `no_prefix` 로 버려진다.

## 사용 시나리오

- **새 접두어**: 대리 봇이 `[도리 대리 · 소유자 요청 https://discord.com/channels/…] 내일 3시 회의 잡아줘` 를 쓴다. 오토파지는 예전과 똑같이 원문을 읽어 소유자 작성·같은 서버·24시간·1회를 확인하고 요청을 처리한다. 게이트웨이 로그에 `prefix=current` 가 남는다.
- **옛 접두어**: `[오모냥 대리 · …]` 요청도 같은 결과로 처리되고 로그에 `prefix=legacy` 가 남는다. 이 줄이 더 나오지 않으면 옛 이름을 지울 때다.
- **거부**: 다른 봇이 `[도리 대리 · …]` 를 흉내 내면 예전처럼 버린다(신원은 이름이 아니라 봇 id 다). 원문이 소유자가 쓴 글이 아니면 `origin_author` 로 원문 검증에서 떨어진다.

외부효과는 여전히 요청별 승인 스레드의 소유자 ✅ 가 있어야 실행된다.
