# 승인 범위 정렬 — 계정 안 쓰기는 카드 없이

## 무엇을
은퇴한 “모든 요청에 승인 카드” 경로를 정리한다. 카드는 cytoplasm 릴리스와
소유자 계정 밖으로 나가는 작업에만 쓰고, 계정 안 일정·문서·할 일·Obsidian
쓰기는 dori-gate로 처리한다.

## 왜
Hermes 전용 도구 게이트와 위키 워처, 할 일 요청 명령과 문서가 옛 규칙을
남겨 두어 같은 내부 쓰기를 다시 승인하도록 안내했다.

## 사용 시나리오
소유자가 Discord에서 개인 일정이나 할 일을 등록하라고 요청하면,
dori-gate가 원문 작성자·서버·시각을 확인하고 쓰기·재조회·변경 기록을 남긴다.
추가 승인 카드는 없다. 외부 참석자 초대나 메일 발송·외부 공유가 포함되면
기존 전용 카드를 먼저 올리고 소유자 승인 뒤 실행한다.

소유자 메시지를 확인할 수 없거나 외부 문서·메일·다른 봇의 글만 있으면 쓰지 않는다.
할 일의 새 `request` 명령은 없으며 `create`와 `write-now`는 같은 소유자 명령
쓰기 경로다. 이미 저장된 할 일 카드는 기존 워처가 기존 해시·일회 claim으로
처리할 수 있게 보존한다.

잔존 관측이며 실제 제거는 선언된 릴리스 경로가 맡는다. 이 문서는 배포 영수증이 아니다.
